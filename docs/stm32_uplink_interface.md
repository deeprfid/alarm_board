# STM32F0 中继板上行包格式

上行方向: STM32F0 中继板 -> Linux。定长 32 字节, 帧头 0xFF。

## 1. 帧结构

| 偏移 | 长度 | 字段 | 取值 / 说明 |
| --- | --- | --- | --- |
| 0 | 1 | FrameHead | 0xFF |
| 1 | 1 | Pdu_len | 32 |
| 2 | 1 | DeviceID | 设备号 |
| 3 | 1 | AntID | 0 = 整机聚合上报 |
| 4..29 | 26 | — | 见第 3 节 |
| 30 | 1 | CRC 低字节 | CRC-16/CCITT-FALSE, 覆盖偏移 0..29 |
| 31 | 1 | CRC 高字节 | 小端(低字节在前) |

CRC 参数: poly 0x1021, 初值 0xFFFF, 逐位 MSB 优先, 不反射, 无终值异或。
自检向量: "123456789" -> 0x29B1。

## 2. 数据包结构体

与固件 BSP/app.h 中的定义一致(共 32 字节, 无填充: 4 + 8 + 8 + 10 = 30, uint16 crc 落在偏移 30):

```c
typedef struct
{
    uint8_t  FrameHead;        /* 偏移 0    0xFF */
    uint8_t  Pdu_len;          /* 偏移 1    32   */
    uint8_t  DeviceID;         /* 偏移 2         */
    uint8_t  AntID;            /* 偏移 3    0 = 整机聚合 */
    uint8_t  Rad_Status[8];    /* 偏移 4    天线1..8: 1=有人, 0=无人 */
    uint8_t  Alarm_Done[8];    /* 偏移 12   天线1..8: 1=正在声光报警, 0=未报警 */
    uint8_t  GPIO[10];         /* 偏移 20   预留, 当前全 0 */
    uint16_t crc;              /* 偏移 30   CRC-16/CCITT-FALSE, 小端 */
} gpio_pdu;
```

说明:

- Rad_Status / Alarm_Done 的下标 0 对应天线1, 下标 7 对应天线8;
- 结构体无填充, sizeof(gpio_pdu) == 32; 直接 memcpy 即可, 也可按上表偏移逐字节取;
- crc 字段为小端存储, 校验范围是偏移 0..29;
- C++ 解析实现见 docs/stm32_gpio_pdu.hpp。

## 3. 字段定义

| 偏移 | 长度 | 字段 | 取值 / 说明 |
| --- | --- | --- | --- |
| 4 | 8 | Rad_Status[8] | 天线 1..8 有人状态: 1 = 有人, 0 = 无人 |
| 12 | 8 | Alarm_Done[8] | 天线 1..8 报警状态: 1 = 正在声光报警, 0 = 未报警 |
| 20 | 10 | GPIO[10] | 预留, 当前全 0 |

## 4. 示例

天线1、天线3 有人, 其中天线3 正在报警:

   偏移 0..3   : FF 20 00 00               帧头=0xFF, Pdu_len=32, DeviceID=0, AntID=0
   偏移 4..11  : 01 00 01 00 00 00 00 00   天线1=1, 天线3=1
   偏移 12..19 : 00 00 01 00 00 00 00 00   天线3=1(报警中)
   偏移 20..29 : 00 00 00 00 00 00 00 00 00 00
   偏移 30..31 : 2E 8B                     CRC = 0x8B2E

整帧:

   FF 20 00 00 01 00 01 00 00 00 00 00 00 00 01 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 2E 8B
