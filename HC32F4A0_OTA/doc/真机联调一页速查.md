## 3. F4A0 联调（H1-H9）

### H1 首烧 → 跳 App
烧 merged_f4a0.hex → 上电 → App 运行（标志区 0xF0000 为 0xFF = 正常引导）。

### H2 网络升级（H2）
设备 HTTP 命令下发 `ota_update`：
```json
{ "cmd": "ota_update", "command_data": "http://<PC_IP>:8080/ota/pkg?id=fw_01020000.otapkg" }
```
预期：下载→验签→NEED_COMMIT→复位→bootloader commit(Bank B)→swap→新固件→confirm。

### H3/H4 本地升级（UART0 / USB1-CDC）
```bat
python ota_upgrade_tool.py uart --port COM3 --baud 115200 --pkg server_data\firmware\fw_01020000.otapkg   :: UART0
python ota_upgrade_tool.py uart --port COM9 --baud 115200 --pkg server_data\firmware\fw_01020000.otapkg   :: USB1
```

### H5 断点续传
升级 ~50% 时 Ctrl+C（或拔线）→ 重跑同命令 → 设备回 0x52(偏移) → 自动续传。

### H6 断电 / H7 坏固件回滚 / H8 安全拒收
- 断电：下载/commit/自检各阶段断电 → 上电应恢复或保持旧版（不砖）
- 坏固件：篡改包后升级 → 新固件起不来 → boot count 3 次后自动回滚旧版
- 安全：LEVEL2/3 固件拒收无签名/篡改包

### H9 RK（如有板）
```bat
python tools/rk_ota_agent.py --config rk_agent.json    :: 应用原子替换 + 服务重启 + 回滚
```

## 4. F460 联调（H10-H12）

### H10 首烧
烧 `tools/merged_f460.hex` → 上电 → App（0x16000）运行。

### H11 本地升级（UART0）
```bat
python ota_upgrade_tool.py uart --port COMx --baud 115200 --pkg server_data\firmware\fw_f460_01020000.otapkg
```
预期：OTA1 帧 → QSPI 暂存 → 完成 → 备份旧固件 → NEED_COMMIT → 复位 → bootloader 覆盖写(0x16000) → 自检 → confirm。

### H12 断电/回滚
升级各阶段断电 → 上电恢复（QSPI 备份）；坏固件 → boot count 超限自动回滚。

## 5. 常用命令速查

```bat
:: 打包（F4A0=platform 2 / F460=platform 1）
python ota_pack.py <app_hex> --version 0x01020000 --platform 2 --app 0 -o <out.otapkg>

:: 上位机
python ota_upgrade_tool.py check  --server http://127.0.0.1:8080 --platform 2 --app 0 --version 0x01010000
python ota_upgrade_tool.py download --server http://127.0.0.1:8080 --platform 2 --app 0 --version 0 --out fw.otapkg
python ota_upgrade_tool.py devices --server http://127.0.0.1:8080 --csv devices.csv   :: 批量

:: 一键构建+验收
python build_ota.py            :: 编译 0E/0W→hex→体积→打包→合并→验收 9/9
python ota_acceptance.py       :: 软件层回归

:: 密钥
python ota_keygen.py -o key.bin && python ota_keygen.py --c-header key.bin   :: 生成+设备端 C 头
```

## 6. 常见问题

| 现象 | 处理 |
|---|---|
| 设备连不上服务器 | 确认 PC_IP/端口；MCU 用 HTTP+包签名（省 TLS） |
| 验签失败 | 打包 key 与设备 OTA_SEC_KEY 一致（demo key 或正式 key 分发） |
| 升级后起不来 | boot count 3 次自动回滚；若仍异常检查 QSPI 备份区 |
| 串口无响应 | 确认波特率 115200、设备工作模式、UART 口（F460 用 UART0） |
